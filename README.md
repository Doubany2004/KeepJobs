# KeepJobs

-Français :
Un site web qui permet de garder les jobs ou les stages auxquels on postule pour suivre son évolution 
Elle aide les utilisateurs à visualiser l'évolution de leurs candidatures dans n'importe quel site d'emploi il poste et de garder une trace de leur démarche le site est héberger sur firebase hosting 

. Fonctionnalité:
Création de compte: chaque utilisateur crée son compte
Connexion: permet à l'utilisateur de se connecter grâce à son email et a son mot de passe 
Ajout de job : l'utilisateur ajout le job auquel il a postulé 
Détail job : c'est la partie ou se trouve tous les détails du job ( poste, entreprise, statut, salaire type d'emploi) 

. Technologie
HTML
CSS
JavaScript 
Firebase(hosting ,Authentification )

-English :
A web application that allows users to save and track the jobs or internships they apply for.
It helps users visualize the progress of their applications across any job website and keep a clear record of all their submissions.
The site is hosted on Firebase Hosting. 

Features:
Account creation : each user creates their own account.
Login system : users can sign in using their email and password.
Add job : users can add the job or internship they applied for.
Job details : section containing all job information (position, company, status, salary, employment type).

Technologies:
HTML
CSS
JavaScript
Firebase (Hosting, Authentication)
